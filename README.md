# Secure Socket on MCU

面向微控制器的輕量級安全通訊原型，探索在嵌入式環境中整合公鑰密碼學與結構化訊息交換。

## 專案簡介

**Secure-socket** 是一個實驗性專案，旨在探索微控制器與伺服器之間的安全通訊實作。

目前的客戶端以 ESP8266 為基礎，透過 Wi-Fi 建立 TCP 連線，並使用 CBOR 編碼格式交換公鑰資訊。

本專案著重於在資源受限的嵌入式環境中，整合密碼學原語、網路通訊與持久化金鑰儲存機制。

## 功能特色

- **Wi-Fi 網路連線**：使用 ESP8266 Wi-Fi 函式庫連接無線網路。
- **TCP 客戶端**：連接至可設定的伺服器位址與連接埠。
- **Ed25519 金鑰管理**：產生 Ed25519 金鑰對，並在檔案系統可用時嘗試將金鑰保存至 LittleFS。
- **公鑰交換**：將公鑰資訊序列化為 CBOR 訊息，以供客戶端與伺服器交換。
- **連線復原**：包含 Wi-Fi 重新連線與 TCP 連線重試機制。
- **嵌入式密碼學實驗**：整合 Ed25519 與 Ascon-128 相關函式庫，探索密碼學在微控制器上的應用。

```text
│                          │
│  Wi-Fi / TCP 客戶端      │

             │

│  連線處理                │

```

此架構圖呈現預期的通訊結構。伺服器端的實際處理流程，以及完整密碼學協定的實作狀態，仍須以對應原始碼為準。

## 開始使用

### 環境需求

- ESP8266 開發板
- Arduino IDE 或相容的 Arduino 建置環境
- ESP8266 開發板支援套件
- 程式所需的函式庫：
  - CBOR
  - YACL
  - Ed25519
  - Ascon-128
  - Ticker
  - LittleFS

部分網路與檔案系統函式庫可能已包含在 ESP8266 Arduino 核心套件中。

### 設定連線參數

在編譯與上傳程式前，請先於原始碼中設定 Wi-Fi 憑證與伺服器端點：

```cpp
const char* ssid     = "YOUR_WIFI_SSID";
const char* password = "YOUR_WIFI_PASSWORD";
const char* host     = "YOUR_SERVER_IP";
const unsigned int port = 12345;
```

請將範例值替換為實際測試環境的設定。

**請勿將真實的 Wi-Fi 憑證、私鑰或其他機密資訊提交至版本控制系統。**

### 編譯與執行

1. 安裝 ESP8266 開發板支援套件及所需函式庫。
2. 設定 Wi-Fi 憑證與伺服器端點。
3. 準備並啟動相容的伺服器端程式。
4. 使用 Arduino IDE 開啟對應的程式草稿。
5. 選擇正確的 ESP8266 開發板與序列埠。
6. 編譯並將程式上傳至開發板。
7. 開啟鮑率為 **115200 baud** 的序列監控視窗，觀察連線與金鑰交換訊息。

伺服器端必須實作相容的通訊協定，客戶端才能完成預期的交換流程。

## 開發狀態

本專案目前仍處於開發與實驗階段。

現有客戶端程式包含 Wi-Fi 連線、TCP 連線處理、Ed25519 金鑰產生與持久化，以及基於 CBOR 的公鑰交換流程。

在將本專案視為完整的安全通訊協定之前，仍有下列項目需要進一步實作或驗證：

- 完整實作並驗證密碼學金鑰建立協定。
- 驗證遠端伺服器的身分，以降低中間人攻擊風險。
- 整合並驗證應用層資料的認證加密機制。
- 定義訊息框架、解析規則與異常輸入處理方式。
- 改善逾時處理及連線狀態管理。
- 檢視金鑰產生、儲存與復原流程。
- 在實際網路環境中測試互通性與安全性。

**注意：** 單純交換公鑰並不足以建立安全的通訊通道。專案中存在密碼學函式庫，也不代表加密、身分認證或完整性保護機制已經完整實作。
